# 📊 Netflix Data Analysis

## 📌 Project Overview

This project focuses on performing **Exploratory Data Analysis (EDA)** on the Netflix dataset to uncover trends in content distribution, growth patterns, and genre popularity. The analysis provides insights into how Netflix has expanded its content library over time.

---

## 🎯 Objective

* Analyze Netflix dataset to understand content trends
* Identify distribution of Movies vs TV Shows
* Study growth of content over the years
* Discover top contributing countries
* Analyze genre popularity

---

## 🛠️ Tools & Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

---

## 📂 Dataset

* Source: Kaggle
* Dataset: Netflix Movies and TV Shows
* Records: ~8800 entries

---

## 🔧 Data Preprocessing

* Handled missing values in columns like director, cast, country, and rating
* Converted `date_added` column to datetime format
* Removed invalid or missing date entries
* Extracted new features such as:

  * Year Added
  * Month Added

---

## 📊 Key Analysis Performed

### 1. Content Type Distribution

* Compared number of Movies vs TV Shows

### 2. Content Growth Over Time

* Analyzed yearly addition of content

### 3. Country-wise Analysis

* Identified top content-producing countries

### 4. Genre Analysis

* Extracted and analyzed most popular genres

### 5. Trend Analysis

* Compared Movies and TV Shows growth over time

---

## 🧠 Key Insights

* Netflix content has grown significantly after 2015, indicating rapid platform expansion
* Movies dominate the platform compared to TV Shows
* The United States is the leading content producer, followed by India
* Drama and Comedy are the most popular genres
* Netflix maintains a diverse and globally distributed content library
